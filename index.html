Enamel AI: an AI receptionist for dental practices

Founder & sole engineer · Sep 2026 – now · pre-launch, live demo line
  • Voice receptionist ("Sarah", on Vapi) that books, reschedules and takes messages against the live clinic diary, with booking safety enforced on the server: read-back before booking, practitioner checks, new-patient handling.
  • Patient-call simulation harness to test the agent: raised the pass rate from 33 to 41 of 42 scenarios.
  • Booking integrity so double-bookings can't happen: database write locks, idempotent retries, held slots when a calendar sync is uncertain, Europe/London time handling across BST changes.
  • Multi-tenant access (organisation → practices → staff roles), hashed sessions, Postgres-backed rate limiting, GDPR retention defaults.
  • "Ask Enamel": an LLM assistant whose agent mode runs up to 8 tasks in parallel and asks for confirmation before anything outward-facing.
  • 80+ merged pull requests and about 47 API integration test suites in CI; deployed on Oracle Cloud with automated backups, restore testing and uptime alerts.
